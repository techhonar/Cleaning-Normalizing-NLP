# Persian NLP Cleaning & Normalization Pipeline

A lightweight, robust, and zero-dependency Python preprocessing pipeline specifically tailored for Persian text processing in NLP tasks.

یک پایپ‌لاین پیش‌پردازش، پاک‌سازی ساختاری و نرمال‌سازی چهارسطحی متن فارسی، طراحی‌شده با استفاده از کتابخانه‌های استاندارد پایتون و بدون وابستگی خارجی.

---

## ویژگی‌ها (Key Features)

- **پاک‌سازی داده‌های وب و ساختاری (Cleaning):**
  - تبدیل خودکار HTML Entities و حذف تگ‌های HTML.
  - حذف کاراکترهای مخرب و نامرئی (Zero-width spaces, BOM, Direction overrides) با حفظ عامدانه نیم‌فاصله (`ZWNJ`) و پیونددهنده ایموجی (`ZWJ`).
  - ناشناس‌سازی اطلاعات هویتی و شخصی (PII) نظیر شماره موبایل و آدرس ایمیل.
  
- **نرمال‌سازی چهارسطحی (Four-Level Normalization):**
  1. **سطح نویسه (Character Level):** ترکیب سازگار یونیکد (NFKC)، یکدست‌سازی حروف عربی («ي» و «ك») به فارسی («ی» و «ک»)، حذف اعراب و خطوط کشیده (تطویل).
  2. **سطح قالب (Format Level):** یکدست‌سازی ارقام عربی/انگلیسی به فارسی و جایگزینی با نشانه‌های ثابت (`<URL>`, `<NUM>`, `<EMAIL>`, `<PHONE>`).
  3. **سطح واژه (Word Level):** کاهش حروف تکراری احساسی («سلاااام» به «سلام») و یکپارچه‌سازی علائم نگارشی («!!!!» به «!» و «...» به «…»).
  4. **سطح فاصله (Spacing Level):** تصحیح خودکار نیم‌فاصله برای افعال («می‌روم»، «نمی‌دانم») و پسوندها («کتاب‌ها»، «بزرگ‌تر») به همراه تنظیم فاصله اطراف نشانه‌های نگارشی.

- **پاک‌سازی وابسته به مسئله (Task-Dependent Cleaning):**
  - پشتیبانی از حالت‌های `general`, `sentiment`, `topic`, `ner` برای تطبیق استراتژی پردازش با نوع مسئله.
  
- **سنجش کیفیت و آمار:**
  - محاسبه تغییرات طول، تعداد کل توکن‌ها، اندازه واژگان ($V$) و نسبت الفبای فارسی.
  - تست خودکار تغییرناپذیری در تکرار (Idempotency Verification).

```text

       │
       ▼
 [۱. پاک‌سازی - Cleaning]
 ├── تبدیل Entityهای HTML
 ├── حذف تگ‌ها و کاراکترهای نامرئی
 ├── ناشناس‌سازی PII (موبایل و ایمیل)
 └── مدیریت لینک‌ها، منشن‌ها و هشتگ‌ها
       │
       ▼
 [۲. نرمال‌سازی - Normalization]
 ├── ترکیب NFKC و نگاشت ک/ی و ارقام
 ├── حذف اعراب و کشیدگی حروف
 ├── اصلاح نیم‌فاصله‌ها و فواصل نگارشی
 └── کاهش حروف و علائم تکراری
       │
       ▼
 متن استاندارد (Normalized Text) + گزارش آماری و تست Idempotent
